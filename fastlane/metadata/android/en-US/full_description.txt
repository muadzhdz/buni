Buni is a defensive, high-performance network privacy shield and in-memory DNS sinkhole for Android.

Key Features:
- Local DNS Sinkhole: Intercepts UDP port 53 via Android VpnService (10.233.0.1/30). Matches queries against an in-memory blocklist, returning synthetic replies (0.0.0.0 for IPv4, :: for IPv6) with 0ms roundtrip.
- Encrypted DNS Uplink: Clean, permitted queries resolve securely over protected TLS sockets using DNS over HTTPS (DoH / RFC 8484) or custom upstream DNS.
- Universal OEM & Ad Protection: Pre-configured to terminate ad networks, analytics trackers, and invasive vendor telemetry across Android devices.
- Modular Filtering: Granular toggles for ads, telemetry/trackers, and malicious endpoints.
- Per-App Bypass: Selectively exclude specific applications to connect directly to WAN.
- Dual Theme Engine: High-contrast Zinc daylight and OLED obsidian stealth themes with automatic system switching.
- Bilingual Localization: Dynamic runtime switching between English and Indonesian.
- Zero-Bloat Architecture: Pure userspace Kotlin implementation with zero trackers, zero analytics, and no external dependencies.
